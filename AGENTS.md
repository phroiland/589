# AGENTS.md

This file defines mandatory repository-wide requirements for AI coding agents.

## ⛔ REQUIRED READING: the master code standard

Before planning, writing, debugging, reviewing, testing, or documenting anything in
this repository, read the master code standard:

    ~/dev/obsidian-dev/code-standard-master-vault/Code-Standard.md

It is the one standard every repo shares: the development loop, testing, git and
commits, code style, architecture boundaries, design, writing, scope, tooling,
memory, and security. Read it at session start. Having read it in a previous
session does not count.

The standard is the floor, not the ceiling. This repo's own rules below and the
notes in its project vault add to it and may be stricter. Where a repo document and
the standard genuinely disagree, the repo document wins for this repo and the
disagreement is recorded in the standard's Open Conflicts note rather than resolved
silently.
